### 3. 传输层、TCP/BBR/QUIC 与高阶传控（第 4–6、15、17 章）

| 中文名词 | 英文名称 / 缩写 | 核心定义与考点提示 | 章节 |
| :--- | :--- | :--- | :--- |
| 多路复用 / 分解 | Multiplexing / Demultiplexing | 发送端封装传输层首部复用同一网络层，接收端依据端口/四元组分发到套接字 | §4.1 |
| 可靠数据传输 | Reliable Data Transfer (rdt) | 在不可靠信道上通过校验和、ACK/NAK、序号、定时器实现无差错有序交付 | §4.4 |
| 回退 N 步 | Go-Back-N (GBN) | 累计确认，接收端不缓存失序分组，超时后重传窗口内全部未确认分组 | §4.5 |
| 选择重传 | Selective Repeat (SR) | 逐个确认，接收端缓存失序分组，仅重传真正丢失或超时的分组 | §4.5 |
| 差异化可靠传输 | DRTP | 依据业务对可靠性与时延的不同需求提供分级可靠传输保障 | §4.6 |
| 三次握手 / 四次挥手 | Three-Way Handshake / Four-Way Wave | TCP 建立双向同步连接与全双工独立关闭连接的状态机流程 | §5.3 |
| SYN 泛洪 / SYN Cookie | SYN Flood / SYN Cookie | 耗尽半连接队列的攻击；服务端不分配状态而将连接参数编码进 ISN 的防御 | §5.3 |
| 糊涂窗口综合征 | Silly Window Syndrome | 双方每次仅发送/通告极小字节导致有效载荷率极低，用 Nagle/延迟确认等缓解 | §5.4 |
| 加法增大乘法减小 | AIMD | 拥塞避免线性增窗、丢包时乘性减窗，保证多流收敛到公平线 | §5.5–5.6 |
| 缓冲区膨胀 | Bufferbloat | 路由器过深队列在丢包前积累巨大排队时延，导致基于丢包的 CC 高延迟 | §6.1 |
| Kleinrock 最优点 | Kleinrock's Optimal Point | 在保持满带宽（BtlBw）的同时使队列排队时延最小（$\text{inflight}=\text{BDP}$） | §6.2 |
| BBR | Bottleneck Bandwidth and RTT | 基于带宽与最小 RTT 测量而非丢包驱动的拥塞控制，含 4 个状态机 | §6.2 |
| QUIC | Quick UDP Internet Connections | 基于 UDP 的加密多路复用传输协议（HTTP/3 底层），支持 0-RTT 与连接迁移 | §6.3 |
| 连接迁移 | Connection Migration (CID) | QUIC 使用连接 ID（CID）而非四元组标识连接，网络切换不断连 | §6.3 |
| 跨层多路径调度 | CPS / MEC-TCP / CECC / LUCP | 面向 5G+Wi-Fi 异构/边缘/高动态场景的现代跨层传控算法族 | §6.4 |
| 选择确认 | SACK (Selective ACK) | TCP 选项字段，向发送端通告已收到的不连续数据块，避免不必要重传 | §15.2 |
| 显式拥塞通知 | ECN | 路由器在 IP 头标记 `CE` 而非直接丢包，接收端通过 `ECE` 通知发送端降速 | §17.1 |
| 主动队列管理 | AQM (RED / CoDel / PIE / FQ-CoDel) | 在队列溢出前按概率或驻留时间主动标记/丢包，抑制 Bufferbloat | §17.2 |
| 低延迟低丢包可扩展吞吐 | L4S (RFC 9330) | 基于精确 ECN 反馈与双队列（Classic/L4S）实现亚毫秒排队时延的架构 | §17.6 |
